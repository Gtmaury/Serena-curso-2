# Design System

<!-- impeccable:design-schema 1 -->

## World

Cream Editorial Atelier — quiet skincare-magazine landing: warm off-white canvas, oversized sage serif display words, overlapping photo plates, outline pill CTAs. Replaces Powder Compact Atelier (plum velvet / dual circles).

## Palette

| Token | Hex | Role |
|-------|-----|------|
| cream | `#f5f2eb` | page ground |
| cream-deep | `#ebe6dc` | section shift |
| ink | `#1c1a17` | text / solid CTA |
| mute | `#6a645c` | secondary text |
| sage | `#8b9a78` | display accent + outline pills |
| sage-deep | `#6f7d5f` | hover / emphasis |
| sand | `#c9b89a` | soft dust particle tone |

## Typography

- Display: **Bodoni Moda** (Beauty, room, price watermark)
- Body / UI: **Manrope**

## Components

- Editorial hero: massive sage “Beauty” with overlapping eye + Anna plates
- Outline pill CTAs (Catalog-style); solid ink pill for primary WhatsApp
- Hairline list rows (why / includes / timeline)
- Soft dust particles below hero only

## Motion

Quiet rise on section titles and key plates; respect `prefers-reduced-motion`.
